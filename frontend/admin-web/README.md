# Admin Web

Ứng dụng Next.js độc lập dành cho quản trị viên.

## Chạy local

```bash
npm install
npm run dev
```

Sao chép `.env.example` thành `.env.local`. Không đặt OpenAI API key hoặc Supabase service-role key trong frontend.

## Kiểm tra

```bash
npm run lint
npm run type-check
npm test
npm run build
```
